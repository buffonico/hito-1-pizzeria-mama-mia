## Pizzeria Mamma Mia con React + Vite

Proyecto Estatico, creado con React + Vite, para una pizzeria

## Acceso

https://github.com/buffonico/hito-1-pizzeria_mamma_mia/
https://buffonico.github.io/hito-1-pizzeria_mamma_mia/


## Descripción

    Nuestra pagina nos permite ver una landig page de una pizzeria, que simula el carritos con un total, ademas de login y logout. 

    Además nos muestra un menu de productos para consumo.
  

## Tecnologías Utilizadas

- HTML5
- CSS3
- JS
- React + Vite
